# 学習院メモポータル

学習院大学生向けの非公式ポータルサイトです。

## 主な機能
- 公式リンクの検索・カテゴリ絞り込み・ピン留め
- 時間割の自動保存と今日の授業表示（2024年度以降の105分授業）
- 課題の追加・編集・完了・削除、締切順表示と優先度
- 課題のカレンダー書き出し（.ics）
- メモの自動保存とコピー
- JSONバックアップの保存・検証付き復元
- ダークモードとスマートフォン向けレイアウト

## データ
既存の gu_portal_*_v3 キーを維持しています。登録内容は利用しているブラウザの localStorage に保存され、サーバーへの送信や端末間の自動同期はありません。ブラウザのデータ消去前や端末移行時には「データ・設定」でバックアップを保存してください。読み込みは現在のデータを置き換えます。

## 授業情報
時間帯は https://www.univ.gakushuin.ac.jp/news/21954.html に基づきます。曜日ごとの登録内容を表示するため、祝日・休講・補講の自動判定はありません。最新情報はG-Port・学年暦・各LMSで確認してください。

## 公開
GitHub Pages の main / (root) から公開します。ビルドや外部依存パッケージは不要です。
